# Gestores de paquetes en Windows (winget)

## Recursos
Páginas para descargar e instalar desde la terminal:
- [winstall](https://winstall.app/)
- [winget-run](https://winget.run/)

## Instalar Terminal
- Windows Terminal: múltiples terminales
```bash
  winget install WindowsTerminal
```
- PowerShell: terminal actualizada de Windows
```bash
  winget install PowerShell
```
