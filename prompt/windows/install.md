# Instalar Starship en Windows

```bash
  winget install starship
```

**Para cmd se necesita Clink**
```bash
  winget install clink
```

La inicialización por shell se documenta en:
- PowerShell: [../../shell/windows/powershell.md](../../shell/windows/powershell.md)
- CMD (vía Clink + starship.lua): [../../shell/windows/cmd.md](../cmd.md)

La configuración del prompt (tema, símbolos, hora) se documenta en [../README.md](../README.md).
